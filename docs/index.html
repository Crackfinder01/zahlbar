Swiss QR-bills that tell you who paid.

Create QR-bills, drop in the camt.054 file from your bank, and see at a glance which invoices are paid, partly paid or overdue. Open source. Runs on your own machine. Built for n8n and AI agents.

Star it on GitHub Self-host in 2 minutes 
$ zahlbar invoice create --number 2026-0042 --amount 1949.75 --due 2026-12-31
$ zahlbar invoice bill 3f9c2a1b7d04 -o invoice.pdf
$ zahlbar reconcile ~/Downloads/camt054.xml
{ "matched": 7, "partial": 1, "unmatched": 0, "duplicates": 0 }
$ zahlbar invoice list --status overdue

Automate it with n8n

A community node plus ready-made workflows: your bank e-mails the camt.054 → invoices are marked paid; every morning → list of overdue invoices.

Why Zahlbar

  • Open source (AGPL-3.0), no account, no tracking
  • Structured addresses only — compliant since 21 Nov 2025
  • REST API with OpenAPI docs, API-key auth
  • Payer names and IBANs from bank files are never stored
  • Docker + SQLite: one container, one file
  • CHF and EUR, Swiss and Liechtenstein accounts
